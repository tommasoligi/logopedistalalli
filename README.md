# Sito Logopedista Lalli (multipagina)

Pagine: `index.html`, `servizi.html`, `chi-sono.html`, `faq.html`, `contatti.html`
Condivisi: `style.css`, `script.js`. Opzionale: `contact.php` (serve hosting con PHP).

## GitHub Pages
1. Carica tutti i file nella radice di un repository.
2. Settings → Pages → Deploy from a branch → `main` / `(root)`.

## Da personalizzare
Cerca i testi tra `[parentesi quadre]` e cambia `info@esempio.it` in `contatti.html` e `script.js`.
Nome, P.IVA e link del footer si trovano in fondo a ogni pagina.
